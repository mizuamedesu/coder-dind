# Developer Tools + MDX

全ユーザー向け開発環境。tmux、GitHub CLI、Codex CLI、Claude Code CLI、MDX CLI と MDX skills を同梱しています。code-server（AI拡張なし）、File Browser と Web Terminal を利用できます。

認証は各ユーザーが `codex`、`claude`、`gh auth login`、`mdx auth login` から行ってください。MDX接続にはVPN等の到達性が必要です。

ホームとDinDデータは停止・再起動後も保持されます。VS Code拡張、Gemini、Copilot、Cursorは含みません。
